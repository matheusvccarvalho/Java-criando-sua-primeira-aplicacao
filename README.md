# ☕ Java: criando sua primeira aplicação

Repositório dedicado aos estudos e projetos desenvolvidos durante o curso **Java: criando sua primeira aplicação**, da [Alura](https://www.alura.com.br/).

O objetivo deste repositório é registrar minha evolução no aprendizado de Java, colocando em prática os conceitos apresentados ao longo do curso por meio de exercícios, desafios e pequenos projetos.

## 📚 Projetos desenvolvidos

| Projeto | Descrição |
|---|---|
| `PrimeiroProjeto` | Primeiros passos com Java e desenvolvimento de programas simples. |
| `ProjetoAula01` | Exercícios introdutórios envolvendo variáveis, operações e estrutura de programas. |
| `ProjetoFilme` | Exercícios relacionados a entrada de dados, condicionais e estruturas de repetição. |
| `DesafioBancario` | Desafio de simulação de uma conta bancária. |
| `DesafioModulo` | Exercícios e desafios desenvolvidos durante o curso. |
| `DesafioModulo2` | Desafios envolvendo lógica de programação e estruturas de controle. |
| `Desafio2Modulo` | Exercícios práticos de programação Java. |
| `Fahreint` | Desafio de conversão de temperatura. |

## 🛠️ Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub

## 🎯 Objetivo

Consolidar os fundamentos da linguagem Java e desenvolver minha capacidade de resolver problemas utilizando programação, construindo uma base sólida para projetos mais complexos.
